# Class 06 — Additional material

[Lecture](../../../module-02-hand-data-for-multi-fingered-manipulation/06-learned-in-hand-cube-reorientation.md)

This folder holds the models and the recorded evidence of the continuous positive-Z cube rotation of Class 06.

| Folder | Content |
| --- | --- |
| `models/` | the right LEAP hand and the scene with the MBZUAI cube (MJCF and assets) |
| `data/` | the telemetry of a 300-step run and its summary |
| `evidence/` | frames of the hardware and simulation runs, and the videos |
| `demonstration/` | key frames and the side-by-side video of the in-hand rotation |
| `photos/` | camera views, the cube faces and a contact sheet |
| `code/` | `run_continuous_z_with_iphone_recording.sh`, the launcher of the physical deployment; it calls the deployment bundle, which is not in this repository |
| `FULL_DATA_CONTENTS.txt` | the list of all files |
