# Six worksheet submissions: Classes 12-17

Submit one completed, handwritten and team-signed PDF per class through your assigned private team repository. All deadlines below use **Abu Dhabi time (UTC+4)**.

Replace NN in each filename with your assigned two-digit team number, 01-08. For example, Team01 submits `submissions/class12/Team01-Class12-Claim.pdf` in `2026Autumn-Team01`. Write **Team01** and your project title on every page. Use the same assigned identifier throughout the project.

## How to submit

1. Complete all required pages by hand and obtain every member's signature on the review page.
2. Scan one readable PDF; check orientation, page order and cropping.
3. Use the exact class folder and team-specific filename above in your assigned private repository.
4. Commit and push to remote **main** before the deadline. Open the PDF on GitHub and verify it; local files and unpushed commits are not submissions.

## How it is collected

At each deadline the TA collects the named PDF from each team's remote main branch, records the commit and collection time, and retains that version. The repository, team-specific filename and identifier on every page identify the team after collection. Confirm teaching-team access before the deadline.

No email, separate upload, physical hand-in, release, tag or collection form is required. Later pushes do not replace the collected submission. Keep the initial PDF and place dated, signed later revisions under that class folder's revisions/ directory.

The [editable project record](project-record.md) supports your work; it is not an additional submission. Cite supporting evidence by its existing path in the same private repository. State missing evidence honestly. Keep student IDs and signatures private. Full reading guidance and worked examples remain on the six class pages.
