# Project worksheet downloads and submissions

Use one printable worksheet for each class. Complete it by hand, obtain all team signatures, scan all required pages into one legible PDF, then commit and push it to the assigned private team repository by the class deadline. The TA collects the exact path below. No physical hand-in or interactive PDF form is required.

Classes 12-16 contain two A4 landscape pages each. Class 17 contains both A3 Decision sides plus the A4 evidence/team-review page. Include identified continuations in the same submitted PDF. Print at actual size; scan all pages legibly without cropping.

The [complete blank pack](Submission-Worksheets.pdf) has all 13 pages in class order. [project-record.md](project-record.md) is an editable working record of all six views and all 27 Decision checks, not another required submission form. Do not overwrite completed team records with a new blank template.

Evidence references must resolve to precise paths and run/configuration IDs in the same private repository. Mark missing evidence rather than substituting a planned result. Check the submitted PDF on GitHub and TA read access; a local commit alone is not a submission. Keep the initial worksheet.pdf and save later dated, signed revisions in that class folder's revisions/ directory with a change record. Do not rewrite history. Student IDs and signatures belong only in private team repositories.
