# Class 04 practical instructions

Use the [current Class 04 lesson](https://github.com/asEmbodiedAISyst/2026Autumn/blob/main/2026-autumn/module-01-actuator-data-for-1-dof-systems/04-basic-quantification-of-sim2real-gap.md), the [package entry](https://github.com/asEmbodiedAISyst/2026Autumn/tree/main/2026-autumn/resources/class04/practical#readme), and the [standalone experiment](standalone/README.md). Use the package-local isolated environment for executable work. The standard Class 04 experiment is simulation-only and does not open a serial port. Physical operation is an optional, explicitly enabled extension with its own preparation. Source code, models, and numerical records retain their original values; a saved record or runnable recipe is not evidence of a new physical experiment.
