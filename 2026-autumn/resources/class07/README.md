# Class 07 resources

The [Class 07 course page](../../module-02-hand-data-for-multi-fingered-manipulation/07-rotating-a-cube-with-visual-feedback.md) contains the explanation, worked geometry/projection examples, illustrations, demonstration and activity. It is complete without a phone, physical hand or software installation.

`results/` preserves 500 synthetic known-corner PnP trials and three selected native pose-feature diagnostics. `evidence/` contains earlier reproduction and source records; preserve their dates/scopes rather than treating them as newly run hardware or reliability evaluations. The synthetic exercise has known correspondences and calibration; it is not an image detector or a physical-camera calibration.

The retained native diagnostics reuse adjacent `../class06/code` sources, models, actor and licences. Keep that dependency when preparing an executable example. Perception and native requirements are declared separately in `code/`; environment preparation and execution belong to a separate example package. Reading the supplied records requires neither a live stream nor a simulator.

Student figures and editable delivery masters are in `../../media/class07`. Retain source attribution and licences. Live cube tracking, visual-policy training, finger retargeting and hardware evaluation remain separate extensions.
