# Class 11 resources

The [complete lesson](../../module-03-arm-data-for-guided-interaction/11-sim2real-gap-in-hardware-deployment.md) explains the deployment contract, constructed replay/reset comparison, retained policy records, demonstration, activity and project handoff. The required route uses simulation and supplied evidence. Exact learned-policy weights/processors and physical policy-rollout measurements are not supplied.

Keep the checks distinct: sixty scripted control steps over two simulated seconds test integration-state replay; the reset contrast deliberately omits velocity and other integration-state fields; the separate pusher JSON records 32/50 nominal simulation successes. The replay is not a rerun of that policy. The saved `ik_ok` field is not an episode success fraction: the included evaluator writes its last per-step info. The source videos are collected after each transition.

The replay/reset/result aggregation is reproduced with the bundled model and declared dependencies. The outcome JSON and selected failure/success clips are retained source evidence, while exact inference artifacts and evaluator/run identity remain incomplete. All eighteen failure records end at 450 steps; the included evaluator defaults to 600. Keep that discrepancy visible until the exact run is identified. No hardware driver is included.
