# Class 11 resources

Required checks are constructed simulation replay and aggregation of retained policy-evaluation records. Exact learned-policy weights/processors and physical policy-rollout measurements are not supplied. The complete lesson, demonstration, activity and project handoff are on one student page. The bundled pure simulation model/code and both selected rollout videos support the exercise without a private repository. No hardware driver is included.

Python3.12 environment: requirements-tested-macos.txt. Run code/lesson_lab.py replay, code/lesson_lab.py results --out results/recorded-policy-summary.json, and code/compare_reset.py.
