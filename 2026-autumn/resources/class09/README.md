# Class 09 resources

The complete lecture, demonstration and student activity are on the Class09 student page. This folder contains the standalone simulation bridge/model, two complete retained episodes and the arithmetic/audit helper. Set up Python3.12 with requirements-tested-macos.txt. Original asMagic Python API0.1.4. No hardware driver is included. Model provenance and CERN-OHL-W licence are in consolidation/package/additional_material/model/rebot_b601_rs_mjcf/.

Retained circle/dropout are local fake-phone simulation captures, not physical robot or phone-camera data. CSV actions and states use different sign/scale conventions. Figure generators need the declared authoring dependencies and locally licensed MiSans fonts; font software is not redistributed.
