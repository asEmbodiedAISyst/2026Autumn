# Supporting-material scope

Sixteen-actuator campaign records, paired hardware/simulation samples, parametric and neural comparison code, combined models and held-out result tables.

The source campaign contains 125 events split 72/23/30. Keep event, motor and sample denominators distinct. Fixture mass declarations remain uncertain; fitted terms must not conceal that uncertainty.

See [the package entry page](../README.md) and the linked lesson for the current interpretation. Pure figure-production tools and paper sources are retained privately, not installed as runtime dependencies.
