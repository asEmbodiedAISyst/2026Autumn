# Class05 resources

The complete lecture, demonstration and student activity are on the single Class05 student page. From this directory run `python3 code/lesson_lab.py` (Python3.10+, standard library only). It checks paired metric rows/event grouping and writes results/lesson-summary.json. The saved summary is included.

For the demonstration's model check use Python3.12 and requirements-model.txt, then code/inspect_scene.py --controller H1 (or H2). It compiles a bundled independent-hinge scene and tests the declared boundary, not hardware performance. All referenced meshes are local.

Data scope and measurement distinctions are described in data/README.md. Figures and editable masters are under ../../media/class05. Figure generation uses code/draw_figures.py with a locally supplied MiSans font directory and the packages in source/requirements-figures.txt. No font software is bundled. Source photos/detections are retained unchanged; generated diagrams are schematic and plots reaggregate supplied records. No newly acquired hardware measurements or neural training are claimed.
