# Supporting-material scope

XC330 fixture MJCF, shared meshes, CAD/measurements and validation/rendering scripts; the separate RS06 fixture models and metadata.

Validation establishes model structure and loading. It does not identify physical dynamics or validate a hardware controller.

See [the README of this folder](README.md) and the linked lesson for the current interpretation. Pure figure-production tools and paper sources are retained privately, not installed as runtime dependencies.
