# Class 02 activity — inspect, compare and identify an unknown

Each student inspects one **unpowered XC330** and returns it. An unpowered XL330 is also circulated for comparison. Teams use the official documentation for XC330-M288-T and XL330-M288-T. Keep power disconnected; do not disassemble either device or force its output.

## Inspect and return

Identify the exact model label, output, fixed housing/mounting and connectors. Explain what rotates relative to what. Identify what you can see directly and what has to be learned from the documentation, including available feedback. Return each unit after inspection.

## Compare exact models

Use the original-brand [XC330](https://docs.robotis.com/docs/dxl/model_reference/x_series/xc_series/xc330-m288/) and [XL330](https://docs.robotis.com/docs/dxl/model_reference/x_series/xl_series/xl330-m288/) pages.

| Comparison | Team response |
|---|---|
| Shared property | Name it and give units where relevant |
| Construction or mass difference | Name both exact models and values/materials |
| Torque or speed difference | Include supply, units and rating condition |
| Consequence for a chosen mechanism | Explain why the property matters |
| Unresolved property | Identify what evidence or measurement is still needed |

Can stall torque and no-load speed be achieved simultaneously? Does 4,096 counts/revolution establish accuracy? Explain each answer in one sentence.

## Record and check returns

Keep one short team comparison with labelled inspection notes and source evidence. Equivalent handwritten notes are sufficient. Confirm that every unit has been returned. This activity requires no installation, powered operation or parameter fitting.

## Optional document search

Choose one actuator. Find its original-brand TDS information, UDS/user-manual information and relevant safety documentation. Record actual titles, revisions, URLs and scope. Identify one TDS rating and the UDS instruction or condition governing its use. Do not relabel an operating warning as an SDS or invent a missing file. State one operating condition and one unresolved question.
