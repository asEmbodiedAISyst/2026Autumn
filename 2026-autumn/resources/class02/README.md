# Class 02 supporting resources

[RUN.md](RUN.md), [telemetry-worked-example.md](telemetry-worked-example.md) and [reading-notes.md](reading-notes.md) preserve optional technical resources. No live hardware integration or timed class rehearsal is certified by these files.
