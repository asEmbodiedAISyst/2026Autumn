# 13 Final Project II: Experience

#### Project question

What happens during one interaction, and what can we learn from it?

#### Three components

* **Worked example — 10 minutes:** A command to rotate an object is not a measured rotation. Joint motion, object retention and object orientation are different observations. A drop or manual reset belongs in the episode record.
* **Worksheet review — 15 minutes:** summarize prepared evidence on Worksheet 2 — Experience; challenge an assumption or missing observation.
* **Project studio — 55 minutes:** Draw one representative interaction episode. Instrument or inspect the record needed to distinguish command, response and outcome. Run a pilot if possible; otherwise retain the planned label. Select the next condition because it challenges an assumption, not because it makes a nicer demonstration.

#### Checkpoint

Commit the episode map and one pilot record or an explicit missing-evidence plan. Update the claim if the pilot exposes an untestable condition.
