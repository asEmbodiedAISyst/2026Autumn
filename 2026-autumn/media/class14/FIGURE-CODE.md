# Class 14 figure reproduction

The two class figure families are generated by ../../resources/project-workbook/figure-source/draw_reading_figures.py. The shared figure-records.json identifies declared inputs for every family; font-receipt.json records the genuine MiSans hashes. Locally licensed MiSans Regular/Semibold are needed to reproduce figures; no font binary is redistributed.

From a separate authoring environment with figure-source/requirements.txt, run the generator with --out pointing to the course media directory and --fonts pointing to the licensed fonts directory. It creates class12 through class17 subfolders. It performs deterministic plotting of constructed examples, not training, simulation or hardware control. PDF embeds TrueType; SVG retains editable text, shapes and axes. Published classroom PNGs are the lesson viewing assets.

The class page captions identify which values are invented and what each comparison can establish. Figure creation/inspection is preparation work, not an additional classroom software requirement.
